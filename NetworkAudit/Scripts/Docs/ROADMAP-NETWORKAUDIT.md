# NetworkAudit Roadmap

NetworkAudit is the IT/network monitoring suite within OpsForge.  
It provides real-time surveillance, packet capture, and compliance workflows.

---

## 🔹 Short-Term (0–6 months)
- **Monitoring**
  - ARP logging and TCP connection monitoring.
  - USB insertion detection.
- **Packet Capture**
  - Wireshark-compatible `.pcapng` generation.
  - Integration with SmartSecurity dashboard.
- **Compliance**
  - Automated changelog and metadata exports.
  - CI/CD validation scripts.

---

## 🔹 Mid-Term (6–18 months)
- **Monitoring**
  - Reverse validation and trust-level filtering.
  - Multi-protocol diagnostics.
- **Packet Capture**
  - Session reconstruction and anomaly detection.
  - Integration with DeepForensics for forensic analysis.
- **Compliance**
  - Contributor validation workflows.
  - Automated licensing checks.

---

## 🔹 Long-Term (18+ months)
- **Monitoring**
  - Predictive anomaly detection using AI models.
  - SaaS integration for enterprise IT departments.
- **Packet Capture**
  - Unified packet archive with chain-of-custody.
- **Compliance**
  - Automated compliance certification exports.
  - Enterprise-ready dashboards.

---

## 🚀 Strategic Positioning
NetworkAudit is the **IT/network arm of OpsForge**, complementing SmartSecurity and DeepForensics.
